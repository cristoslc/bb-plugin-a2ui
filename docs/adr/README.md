# Architecture decision records

One file per decision, numbered `NNNN-short-title.md`. Each record has context, the options considered with their costs, the decision, and its consequences. A record is adopted when the change lands and superseded when a later record replaces it; never edit an adopted record's decision, write a new one that supersedes it.
