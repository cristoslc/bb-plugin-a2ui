# docs

Project documentation for `bb-plugin-a2ui`. Start with `AGENTS.md` and `PURPOSE.md` at the repository root, then use this map.

- `ARCHITECTURE.md` — how the plugin sits inside bb and how a stream becomes a card.
- `DEVELOPER-WORKFLOWS.md` — build, test, dev loop, catalog refresh, release.
- `USER-EXPERIENCE.md` — what a reader sees in the card, including errors and accessibility.
- `DOMAIN-MODEL-L1.md` — the A2UI vocabulary this plugin implements, in plain words.
- `agents-detail/` — guidance for agents working in this repository.
- `adr/` — numbered architecture decisions.
- `plans/` — implementation plans and specs.
- `musings/` — pre-artifact notes.
- `retros/` — post-session reflections.
- `tech-debt/` — known debt too large to fix inline.
